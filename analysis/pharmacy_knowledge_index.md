## How to Use These Reports

### When answering chatbot questions:

1. **Identify the topic** from the question (revenue? inventory? customers? competitors?)
2. **Pull relevant benchmarks** from the appropriate report
3. **Compare WF's synthetic data** against industry benchmarks
4. **Provide context** — "Industry average is X, WF is at Y, which means..."
5. **Give actionable recommendations** grounded in what top chains do

### Response depth by mode:

- **[BRIEF]:** One number + one-line context from benchmarks
- **[INSIGHTS]:** Number + benchmark comparison + what-to-do
- **[DEEP]:** Full analysis with tables, charts, industry comparisons, multi-point action plan
